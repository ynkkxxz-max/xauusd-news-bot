# 📢 Telegram Channel Broadcast Standards & Design Rules

- **កាលវិភាគម៉ោង ៧:០០ ព្រឹក (Strict 07:00 AM, Once Per Day)**:
  - ផ្សាយចូល Telegram Channel ត្រឹមតែ **១ ដងគត់ក្នុងមួយថ្ងៃនៅវេលាម៉ោង ៧:០០ ព្រឹក** (ម៉ោងនៅកម្ពុជា UTC+7)។ មិនផ្សាយខុសម៉ោង ឬច្រឡំផ្សាយពេលរសៀល។
- **ទម្រង់ផ្ទាំងរូបភាពកាតមាស Ultra-HD (1080x1080)**:
  - ផ្សាយជាផ្ទាំងរូបភាព Graphic Card កម្រិតច្បាស់ Ultra-HD (1080x1080) មាន background ដុំមាសប្រណីត និងផ្ទាំងកញ្ចក់ Dark Glassmorphic ទំនើប (គ្មានគំនូរទៀន Candlestick កំប៉ិកកំប៉ុកតាមគែមឡើយ)។
  - ចំណងជើងលើ៖ អក្សរ 3D មាសចែងចាំង `ហាងឆេងមាស` (គ្មានពាក្យលើ តម្លៃមាសថ្ងៃនេះ និងគ្មាន Watermark jmsela.com ឡើយ)។
  - ជួរកាលបរិច្ឆេទ និងម៉ោងស្ថិតនៅ **ក្រោមចំណងជើង ហាងឆេងមាស ផ្ទាល់**៖ `ថ្ងៃ {DD/MM/YYYY}   ម៉ោង 07:00 ព្រឹក`។
  - ប្រអប់កាតពណ៌សចំនួន ៣ (White Rounded Pill Cards) នៅចំកណ្តាល បង្ហាញតម្លៃច្បាស់ៗ (គ្មានសញ្ញាចុចពីរ `:` និងមានលេខ `1` នៅខាងមុខ)៖
    1. `1 តម្លឹង`    `$X,XXX`
    2. `1 ជី`        `$XXX`
    3. `1 អោន`      `$X,XXX`
  - ប្រើពុម្ពអក្សរ Kantumruy Pro Black 900 សម្រាប់អក្សរខ្មែរ និង Outfit 900 សម្រាប់លេខតម្លៃដុល្លារ។
  - គ្មានប៊ូតុង Inline Buttons រញ៉េរញ៉ៃឡើយ (`reply_markup=None`)។

### 2. 🚨 Breaking News Standard (វិស័យស្នូលទាំង ៧)
- **ទម្រង់ Layout និង Header សាច់រឿង (Story Headline Header — បញ្ជាផ្ទាល់)**:
  - លុបចោលទាំងស្រុងនូវ Header `🔹 ព្រឹត្តិការណ៍សំខាន់` មិនឱ្យប្រើទៀតជាដាច់ខាត។
  - ចាប់ផ្ដើមផ្ទាល់ពីទង់ជាតិ និងចំណងជើងសាច់រឿងជាភាសាខ្មែរខ្លីខ្លឹមតែម្ដង៖ `{ទង់ជាតិ} <b>ចំណងជើងសាច់រឿងខ្លីទាន់ហេតុការណ៍ជាភាសាខ្មែរ</b>` (ឧ. `🇹🇼 <b>តៃវ៉ាន់អភិវឌ្ឍបច្ចេកវិទ្យា AI ដើម្បីជួយថែទាំអ្នកជំងឺវង្វេងវង្វាន់</b>`)។
  - **ចំណងជើងពេញលេញ គ្មានសញ្ញាចុចបី (Strict Zero-Ellipsis Headline — បញ្ជាផ្ទាល់)**: ចំណងជើង Header ត្រូវតែជាប្រយោគពេញលេញ ខ្លី ខ្លឹម ហាមដាច់ខាតកុំប្រើសញ្ញាចុចៗ (...) ឬ (…), ហាមកាត់ដាច់ពាក្យពាក់កណ្តាល និងហាមបញ្ចប់ដោយសញ្ញាចុចពីរ (:) ឬ (៖) នៅខាងចុងជាដាច់ខាត។
  - រូបភាពព័ត៌មាន (News Image) ត្រូវបង្ហាញនៅខាងលើគេបង្អស់ បន្ទាប់មកទើបជា Caption អត្ថបទដែលមាន Header ទង់ជាតិ+ចំណងជើងខ្មែរនេះ។
- **ទង់ជាតិប្រទេសពាក់ព័ន្ធ (Strict Real Country Flags Only — ហាមដាច់ខាត Emoji កូនក្មេង — បញ្ជាផ្ទាល់)**:
  - ដាក់ទង់ជាតិ **ត្រឹមតែនៅខាងមុខ Header ចំណងជើងតែប៉ុណ្ណោះ** (ឧ. `🇹🇼 <b>...</b>` ឬ `🇺🇸 🇮🇷 <b>...</b>`)។ ហាមដាច់ខាតមិនឱ្យដាក់ទង់ជាតិនៅក្បែរឈ្មោះប្រទេសក្នុងតួអត្ថបទសាច់រឿងឡើយ ដើម្បីឱ្យអត្ថបទរលូន ស្រឡះភ្នែក បែបសារព័ត៌មានអាជីព។
  - **ហាមដាច់ខាតមិនប្រើប្រាស់ Emoji កូនក្មេង (`💻`, `🛢️`, `🪙`, `🏦`, `🌐`, `🥇` ល) នៅខាងមុខចំណងជើងឡើយ**៖ ប្រើតែ **ទង់ជាតិប្រទេសពិតប្រាកដ** ប៉ុណ្ណោះ។ បើជាព័ត៌មានទូទៅ ក្រុមហ៊ុនបច្ចេកវិទ្យា ឬទីផ្សារសកលដែលគ្មានប្រទេសជាក់លាក់ គឺត្រូវចាប់ផ្តើមដោយចំណងជើងអក្សរដិត **`<b>{ចំណងជើងខ្មែរ}</b>`** ស្អាតបាត បែបសារព័ត៌មានអន្តរជាតិអាជីព គ្មាន icon រញ៉េរញ៉ៃឡើយ។
- **ខ្លឹមសាររៀបរាប់ក្បោះក្បាយត្រឹមត្រូវ**:
  - សាច់រឿងព័ត៌មានក្បោះក្បាយ ត្រឹមត្រូវតាមដំណើររឿងពិតជាភាសាខ្មែរសុទ្ធសាធ (គ្មានចំណងជើងភាសាអង់គ្លេសនៅខាងមុខឡើយ)។
  - **ឈ្មោះក្រុមហ៊ុន និងឈ្មោះមនុស្ស/មេដឹកនាំ (Original English/Latin Names — បញ្ជាផ្ទាល់)**: ត្រូវរក្សាទុកជាភាសាដើម (English/Latin) ជានិច្ច ហាមដាច់ខាតកុំបកប្រែ ឬសរសេរកាឡៃជាភាសាខ្មែរឡើយ (ឧ. Apple, Microsoft, NVIDIA, Tesla, Google, Amazon, Meta, Tether, BlackRock, TSMC, Intel, Elon Musk, Donald Trump, Kevin Warsh, Jerome Powell, Xi Jinping, Warren Buffett ជាដើម)។
  - ហាមដាច់ខាតកុំបង្ខំភ្ជាប់រឿងមាស ឬប្រាក់ដុល្លារ ($) បើមិនពាក់ព័ន្ធ។
- **ការបញ្ជាក់ផលប៉ះពាល់ចំគោលដៅ (Targeted Asset Impact Assessment — ចំណុចគោលទី ៣ & ៦ — បញ្ជាផ្ទាល់)**:
  - ឈប់ប្រើឃ្លា template ដដែលៗដូចជា «បង្កើនសម្ពាធលើទីផ្សារ» ឬ «ភាពមិនច្បាស់លាស់នៃសេដ្ឋកិច្ច»។ ត្រូវវិភាគផលប៉ះពាល់ឱ្យចំទ្រព្យសកម្មពិតប្រាកដ (ដូចជា លើតម្លៃមាស XAUUSD, ប្រាក់ដុល្លារ USD, អត្រាការប្រាក់/Yields, សម្ពាធតម្លៃប្រេង, ឬភាគហ៊ុនបច្ចេកវិទ្យា/បន្ទះឈីប)។
  - **ត្រូវប្រើប្រាស់ទម្រង់ស្តង់ដារ និងសញ្ញាសម្គាល់**៖
    - `🔹 ផលវិជ្ជមាន៖ {ការពន្យល់ចំទ្រព្យសកម្ម}` (ប្រើសញ្ញា 🔹 សម្រាប់វិជ្ជមាន)
    - `🔸 ផលអវិជ្ជមាន/ហានិភ័យ៖ {ការពន្យល់ចំទ្រព្យសកម្ម}` ឬ `🔸 ហានិភ័យទីផ្សារ៖ {ការពន្យល់ចំទ្រព្យសកម្ម}` (ប្រើសញ្ញា 🔸 សម្រាប់អវិជ្ជមាន/ហានិភ័យ)
    - ព័ត៌មានដែលមានទាំងសងខាង អាចដាក់ ២ បន្ទាត់បាន។
  - **ហាមដាច់ខាតមិនឱ្យប្រើពាក្យ «វា» នៅខាងមុខឡើយ (ហាមប្រើ «វាផលវិជ្ជមាន» ឬ «វាផលអវិជ្ជមាន» — បញ្ជាផ្ទាល់)**។
  - **ហាមដាច់ខាតមិនឱ្យប្រើវង់ក្រចក `()` ក្នុងបន្ទាត់ផលប៉ះពាល់ជាដាច់ខាត លើកលែងតែឈ្មោះកូដទ្រព្យសកម្មស្តង់ដារដូចជា (XAUUSD), (USD), (BTC) ប៉ុណ្ណោះ**។
  - **ហាមដាច់ខាតមិនផ្សាយព័ត៌មានអព្យាក្រឹត (Zero Neutral News)**: ព័ត៌មានណាដែលជា `ផលអព្យាក្រឹត` ត្រូវទម្លាក់ចោលភ្លាមៗ (Drop/Skip) ហាមមិនឱ្យផ្សាយចូល Channel ឡើយ។
- **កែសម្រួលការបកប្រែពាក្យបច្ចេកទេសផ្លូវការ (Professional Terminology — ចំណុចគោលទី ៤ — បញ្ជាផ្ទាល់)**:
  - កែពាក្យបកខុសន័យមកជាពាក្យបច្ចេកទេសផ្លូវការ៖
    - «ដាក់ឈ្មោះ» $\rightarrow$ «តែងតាំង» / «តែងតាំងជា» (Appoints / Names)
    - «ប៉ះនឹងប្រេង» $\rightarrow$ «សម្ពាធតម្លៃប្រេង»
    - «គម្លាតសាច់ប្រាក់» $\rightarrow$ «កង្វះខាតសាច់ប្រាក់ងាយស្រួល» (Cash crunch)
    - «ការប្រញាប់ប្រញាល់ផ្តល់មូលនិធិ» $\rightarrow$ «ការសម្រុកបញ្ចេញទុនវិនិយោគ» (Funding rush)
    - «សម្រាប់កាណាដា» $\rightarrow$ «ប្រចាំប្រទេសកាណាដា»
    - «ឧបត្ថម្ភដល់សង្គ្រាម» $\rightarrow$ «ចំណាយលើសង្គ្រាម» ឬ «ផ្គត់ផ្គង់សង្គ្រាម» (Financing war)
    - «កប៉ាល់ដឹកជញ្ជូន» (សម្រាប់ Shadow fleet) $\rightarrow$ «កងនាវាស្រមោល» ឬ «នាវាដឹកប្រេងគេចទណ្ឌកម្ម»
    - «ពាក់ទង» (ពាក្យខុសដែលគ្មានក្នុងវចនានុក្រម) $\rightarrow$ «ពាក់ព័ន្ធ» ឬ «ទាក់ទង»
    - «ស្ថានភាពនេះឱ្យឃើញ» (កាត់ខ្វះកិរិយាសព្ទ) $\rightarrow$ «ស្ថានភាពនេះបង្ហាញឱ្យឃើញ»
    - «យោលយោគ» (សម្រាប់ទំនុកចិត្តទីផ្សារ) $\rightarrow$ «រង្គោះរង្គើ» ឬ «ចុះខ្សោយ/ធ្លាក់ចុះ» (Confidence wobbles)
    - Default insurance $\rightarrow$ «ថ្លៃធានារ៉ាប់រងហានិភ័យបំណុល (CDS)»
